Duty Cycle Data Pipeline Automation

Skills used
  • Python
  • SQL
  • Algorithm design & optimization
  • Data structures
  • AI-assisted development (Copilot)
  • Databricks/data lake workflows

This project was completed during an internship. Specific images and data have been withheld or generalized to protect proprietary company information.

Objective

Automate a slow, manual process for retrieving field engine data used in physics-of-failure damage modeling, enabling a reliable data library across hundreds of engines.

Approach

  • The original process required manually reviewing a calendar heat map to find a usable data window for a single engine, then downloading that window's time-series data, a repeated manual lookup per engine that didn't scale
  • Designed and implemented a two-stage pipeline in Python and SQL to replace this:
    • A data availability script that evaluates all engines at once, applying coverage and minimum-window constraints to automatically select the best high-coverage data window per engine, using data structure and algorithm techniques to efficiently search and filter across the full dataset rather than checking each engine individually
    • A data download script that takes the selected windows as input and retrieves the corresponding time-series data per engine
  • Used AI-assisted development to speed up iteration on the Python scripts, and worked closely with the analytics team to align on data requirements and integration with the existing damage modeling workflow
20 min/ESN → 3 min/ESN
Old Process
Manually review a calendar heat map to find a usable data window, one engine at a time
↓
Manually download that window's time-series data (~20 min/ESN)
New Process
Data availability script selects the best high-coverage window for every engine at once
↓
Data download script retrieves the time-series data for each selected window (~3 min/ESN)

Result

Cut data processing time from ~20 minutes to ~3 minutes per engine, an 85% reduction, while scaling the pipeline to a batch of 650 engines in a single run.
